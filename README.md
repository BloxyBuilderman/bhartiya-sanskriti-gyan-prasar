# भारतीय संस्कृति ज्ञान प्रसार — Class 8 Study Portal

A static, mobile-friendly Hindi study website with 11 chapter sections, chapter quizzes, scoring, and a 50-question final test. No build tools or backend required.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub, for example `bharatiya-sanskriti-study`.
2. Upload `index.html` and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. The URL appears on the Pages settings screen and usually looks like `https://YOUR-USERNAME.github.io/bharatiya-sanskriti-study/`.

## Important content note
The summaries and questions are study aids organized around the listed chapter topics. Please compare exact dates and textbook-specific details against the uploaded book before using this for formal exam preparation. The website is static; progress is kept only in the current browser session and is not synced across devices.
